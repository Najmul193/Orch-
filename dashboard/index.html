How routing works

Each task is classified (code / ui / docs / research / data / general) and sent to the best free model for that kind. Simple, non-file tasks use the local model when it is on. Anything rate-limited cools down and the next model takes over automatically. With Fan-out on, a task that has independent parts is split across several agents at once and their results are merged. Before an agent may edit files or run a risky command in a folder you have not trusted, orch pauses and asks your permission — a banner appears at the top with Allow / Deny (and on the diagram).
